# Task: Create skill taxonomy v1 for Data Engineer and AI Engineer jobs

## Goal
Define a first version of technical skill taxonomy for extracting skills from job descriptions.

## Scope
Roles:
- Data Engineer
- AI Engineer

## What to produce
Return a markdown taxonomy document containing:
1. Skill categories
2. Canonical skill names
3. Synonyms and aliases
4. Role relevance mapping
5. Ambiguous term handling
6. Extraction notes

## Example categories
- Programming languages
- Databases
- Data processing
- Cloud platforms
- Orchestration
- ML/AI frameworks
- Vector databases
- DevOps/MLOps
- BI and analytics
- Soft filters only if clearly needed

## Constraints
- Focus on technical skills first
- Avoid overly broad buzzwords
- Make taxonomy directly usable by rule-based extraction
- Include Vietnam/English mixed-text considerations

## Output format
Return markdown with structured tables.
