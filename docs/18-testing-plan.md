# Task: Create testing strategy for the data pipeline

## Goal
Define how to test the crawler, parsers, transformations, and aggregations.

## What to produce
Return a markdown test plan with:
1. Unit tests
2. Integration tests
3. Regression tests
4. Snapshot tests for parsers
5. Data contract tests
6. End-to-end smoke test
7. Suggested test fixtures
8. CI recommendations

## Constraints
- Focus on reliability of public-page crawling and parser stability
- Keep tests lightweight enough for fast iteration
- Design tests for future source expansion

## Output format
Return markdown with sections and examples.
