# Task: Create phased MVP delivery plan

## Goal
Break the implementation into practical milestones for a small Data Engineering project.

## What to produce
Return a markdown plan with:
1. Phase 0: setup and source validation
2. Phase 1: listing + detail crawling
3. Phase 2: parsing + normalized jobs
4. Phase 3: dedup + skill extraction
5. Phase 4: weekly aggregates + alert dataset
6. Phase 5: quality + monitoring + documentation

For each phase include:
- objective
- tasks
- deliverables
- dependencies
- exit criteria
- risks

## Constraints
- Keep scope aligned to MVP
- Prioritize early usable outputs
- Assume one main engineer and AI coding assistance

## Output format
Return markdown with tables or bullet structure.
