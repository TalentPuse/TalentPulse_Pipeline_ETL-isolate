# Task: Design weekly aggregation logic for job market insights

## Goal
Create weekly aggregation logic for the Job Market Trends MVP.

## Required outputs
Weekly metrics for Ho Chi Minh City, focused on Data Engineer and AI Engineer:
- job_post_count
- unique_company_count
- top skills
- rising skills
- jobs by role
- jobs by source
- posting trend by week

## What to produce
Return a markdown design document with:
1. Metric definitions
2. Aggregation grain
3. Required input tables
4. SQL model ideas
5. Rules for week boundaries
6. Rules for rising skills
7. Output table schemas
8. Example report rows

## Constraints
- Make metrics reproducible
- Avoid overly complex forecasting
- Keep it useful for weekly reporting and alert tuning

## Output format
Return markdown with formulas described in plain language and example schemas.
